## 🎨 **Banner Best Practices:**

### **Full Screen Banners:**

**✅ Do:**
- Use high-quality images (1920x600px+)
- Choose images with clear focal points
- Ensure good contrast with text
- Use relevant imagery

**❌ Don't:**
- Use blurry or pixelated images
- Choose busy backgrounds
- Upload images too small
- Use unrelated visuals

---

### **Left/Right Banners (300x300):**

**✅ Do:**
- Use square images (300x300px)
- Choose clear, simple images
- Center the subject
- Use professional photos

**❌ Don't:**
- Use landscape/portrait images
- Crop important parts
- Use cluttered backgrounds
- Upload very large files

## 🔄 **Switching Between Editors:**

### **Simple Text → Rich Text:**

Your text will be preserved!

```
Before (Simple):
Get In Touch
Email: test@example.com

After (Rich Text):
<p>Get In Touch</p>
<p>Email: test@example.com</p>
```

### **Rich Text → Simple:**

HTML tags will be stripped, but content preserved:

```
Before (Rich):
<h1>Title</h1>
<p>Content</p>

After (Simple):
Title
Content
```

## 💡 **Pro Tips:**

### **Tip 1: Line Breaks in Simple Text**

```
Press Enter once:     Single line break
Press Enter twice:    Paragraph break

Example:
Line 1
Line 2        ← Single enter

Paragraph 1

Paragraph 2   ← Double enter
```

### **Tip 2: Emojis Work Great**

```
Use emojis for visual interest:
📧 Email
📱 Phone
🌍 Location
⏰ Hours
```

## 🔧 **Troubleshooting:**

### **Q: Text not showing line breaks?**
**A:** Make sure you're using "Simple Text" mode. Rich Text may merge lines.

### **Q: Banner image too large?**
**A:** Resize before uploading:
- Full Screen: 1920x600px
- Left/Right: 300x300px

### **Q: Banner not showing?**
**A:** Check:
- Banner Type is not "No Banner"
- Image was uploaded successfully
- Image file is not corrupted
- Page is published

### **Q: Content looks weird on mobile?**
**A:** This is automatic! Banners stack vertically on mobile.

### **Q: Want to remove banner?**
**A:** Edit page, change Banner Type to "No Banner", save.
