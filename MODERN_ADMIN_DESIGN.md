- Primary buttons (Save, Submit, Add)
- Active navigation items
- Important highlights
- Call-to-action elements
- Success states
- Primary icons

### **When to Use Blue (#0387C3):**
- Secondary buttons (View Site, Cancel)
- Links
- Information displays
- Secondary icons
- Subtle highlights

### **When to Use Pink-Blue Gradient:**
- Headers
- Large buttons
- Backgrounds
- Hero sections
- Special elements

```

```

### **Border Radius:**
```
Small:    8-12px
Medium:   16px
Large:    20-24px

```

### **Shadows:**
```
Small:    0 2px 8px rgba(...)
Medium:   0 8px 24px rgba(...)

```
